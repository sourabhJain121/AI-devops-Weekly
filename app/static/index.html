🎓 Architectural Highlights for Academic Evaluation
1. Dynamic Intent Routing
Query intent is classified before retrieval, isolating BMU policy, candidate profiles, and company research into distinct pipelines to prevent cross-collection contamination.
2. Anti-Hallucination Bounds
Strict distance filtering and grounded prompt envelopes ensure the LLM answers exclusively from verified chunks, responding with insufficient information when facts are unrecorded.
3. Local Sovereign Inference
Running open-weights models (CodeLlama, StarCoder2, Qwen) completely on local Ollama runtime guarantees absolute student privacy with zero data transmission to external APIs.
